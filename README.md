# Anshin Spa 🌿

*A thoughtful approach to wellness and appointment management.*

Anshin Spa is a Japanese-inspired spa appointment management system designed to bring together a calm, welcoming experience and the technical foundations of a reliable booking platform.

Inspired by Japanese aesthetics, natural textures, and handcrafted details, the project aims to create a digital space where thoughtful design meets practical functionality.

More than a booking calendar, Anshin Spa is an exploration of how software can solve real-world problems while preserving a distinctive visual identity.

## ✦ Project Vision

The goal is to develop a spa management platform that combines an intuitive client experience with organized appointment administration.

The project will explore service management, appointment scheduling, availability control, and the business logic required to support a consistent booking experience.

## ✦ Design Philosophy

Anshin Spa draws inspiration from Japanese craftsmanship and the quiet beauty of natural materials.

Its visual identity revolves around warm sand tones, moss green, vermilion red, and charcoal, complemented by elegant typography and a handcrafted seal-inspired emblem.

Every design decision aims to balance clarity, warmth, and functionality.

## ✦ Technology Stack

* **Frontend:** React + TypeScript
* **Backend:** Java + Spring Boot
* **Database:** PostgreSQL
* **Architecture:** REST API
